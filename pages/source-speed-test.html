用同一首音訊比較目前 Cloudflare OpenList 與 VPS Alist。測試目錄列表、檔案資訊 API、音訊來源 Range 首段與中段回應，並可分別載入 HTML5 Audio。這個頁面只讀取來源，不會寫入 D1、R2 或修改原始檔案。

測試方式

兩邊請指向同一個實際資料夾及同一首音訊。若 VPS 掛載後多了一層目錄前綴，可分別修改左右路徑。每個來源會測試一次目錄列表、三次 /api/fs/get（交錯先後順序），再測試音訊開頭及中段各最多 64 KiB 的 HTTP Range。Token 僅在本頁記憶體中使用，重新整理即清空。
安全提示：Token 會由瀏覽器直接送到各自填寫的 Alist / OpenList 網址，不會送到 FRAME Audio 的 Pages Functions，也不會寫入網址、localStorage、D1、R2 或 GitHub。請只填寫你自己的服務網址與 Token。若 VPS Alist 尚未允許 Preview 網域的 CORS，請加入 https://cf-preview.frame-audio.pages.dev，並允許 POST、OPTIONS 及 Authorization、Content-Type 標頭。
