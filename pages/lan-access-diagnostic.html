OpenList 目標

會自動讀取這個瀏覽器已保存的區域網路網址（僅讀取，不修改）。請確認地址是手機可以直接打開的同一個 OpenList 網址。

下列測試只會連接你填寫的 OpenList 主機，不會呼叫中國移動雲盤，不會讀取檔案、不會掃描資料夾，也不會寫入 D1／R2。只有點擊對應測試按鈕才會送出請求。

測試 A：免登入 GET

呼叫 OpenList 公開設定 API /api/public/settings。這是簡單 GET，不需要帳號密碼，也不會取得檔案下載連結。它可先測試瀏覽器是否允許跨來源讀取區域網路 API。

測試 B：登入 POST

重現 FRAME Audio 現在使用的 POST /api/auth/login，包含 JSON Content-Type 和 targetAddressSpace: "local"。瀏覽器可能先發送 CORS OPTIONS 預檢。成功取得 JWT 後只確認成功，不顯示、不保存 Token。
